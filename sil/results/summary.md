# System simulation (software in the loop)

Generated by `sil/run_sil.py --seed 1`. Each car runs the real device code; reports go through the backend API and the trust engine. Sensor hit rates, radio and network behaviour are assumptions (see the top of `run_sil.py`), so these numbers describe the system logic under those assumptions, not road performance.

*Warned* = a car approaching a real hazard got a warning-level hazard from `GET /hazards` 300 m before it. *Advisory* = it got only an advisory. *Fake warned* = a car got a warning for a hazard an attacker invented. *Any false warning shown* = share of all hazard queries that returned a warning for something that is not a real hazard (invented ones and honest devices' false reports).
